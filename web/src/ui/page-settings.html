AI Agent

Connects to any OpenAI-compatible endpoint: a hosted provider, a gateway, or a model running on your own hardware. A hosted endpoint sends router names, addresses and network shape to that provider. A local one (Ollama, LM Studio, vLLM, LiteLLM) sends nothing outside your network. The AI Agent page appears once this is switched on and an endpoint and model are set.

For an endpoint on your own network with a self-signed certificate. Press Test Connection: if the certificate is not trusted, it is shown with a Trust button that fills this in, then save. Only that exact certificate is accepted afterwards.

The assistant can only change things you are allowed to change yourself, and every change goes through the same checks, confirmation and audit trail as the forms. Turning this off lets it apply ordinary changes without asking. A change that could cut MikroDash off from the router is always put to you, whatever this is set to.

Zero-touch provisioning

New routers run a short script and call home to this MikroDash, then join the fleet on their own. A remote router dials in over a WireGuard tunnel built into MikroDash, so it can sit behind NAT anywhere. This opens one UDP port, which must be published from the container and reachable from the internet; it stays closed while this is off. Routers on your own network need no tunnel.

The public address is a name or IP, with no port. Tunnel addresses must be private and not used on your routers' networks. The LAN address is where local routers call home, and the wizard suggests it.
