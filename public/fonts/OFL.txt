MikroDash bundled fonts — licensing
===================================

MikroDash self-hosts every font it offers in Settings → Appearance, so the
dashboard works on an isolated network with no CDN and no outbound requests.

All bundled fonts are licensed under the SIL Open Font License, Version 1.1.
The font files live in public/fonts/ and public/vendor/fonts/; this notice
covers both directories.

The OFL requires that the copyright notice for each font accompany the font
files. Those notices are reproduced below, exactly as published upstream,
followed by the full text of the licence, which is identical for all of them.
